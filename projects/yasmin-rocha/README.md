# Yasmin Rocha | Athlete Studio

Projeto editorial e comercial independente, resgatado de um protótipo do Lovable e adaptado para Vite/React/TypeScript.

## Desenvolver

`npm install`
`npm run typecheck`
`npm run build`

## Rotas

- `/` página pública editorial
- `/parcerias` propostas comerciais exploratórias
- `/studio` painel de planejamento local, **sem autenticação**: não armazenar dados privados. Dados ficam apenas no localStorage e não sincronizam.

## Dados

As métricas públicas são capturas manuais do Instagram em 11/11/2026. Não há integração com Instagram ou contratos confirmados. Fotografias oficiais dependem de autorização.
